# sealunit

Seal and reshape unit text streams with deterministic transforms.

**Site:** https://theworker02.github.io/sealunit/

## Install / run

```bash
git clone https://github.com/theworker02/sealunit.git
cd sealunit
node src/cli.js
node --test
```
